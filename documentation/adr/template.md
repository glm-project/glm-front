## Context

yet.

- Option A — **kept**.
- Option B — rejected: reason in one line.
- Option C — rejected: reason in one line.

## Decision

What we do, in the imperative, in prose. Enough for a reader to apply it without reading the rest.

## Consequences

### Positive

- What this buys, concretely.

### Negative

Mandatory. An ADR that lists only benefits is not a decision, it is a justification.
