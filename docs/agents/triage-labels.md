# Triage labels

Map the five canonical triage roles to these GitHub label strings:

| Canonical role    | GitHub label      | Meaning                                           |
| ----------------- | ----------------- | ------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue            |
| `needs-info`      | `needs-info`      | Waiting for information from the reporter         |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation                     |
| `wontfix`         | `wontfix`         | Will not be actioned                              |

When a skill names a role, use its mapped label. Edit the GitHub label column to change the vocabulary.
Board field conventions live in [issue-tracker.md](issue-tracker.md).
