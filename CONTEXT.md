# GLM

Vocabulaire métier partagé par la gestion de l'atelier et le pupitre utilisé par les opérateurs.

## Language

### Désignation au pupitre

**Matricule** :
Code de l'opérateur dans le référentiel de l'entreprise, également utilisé pour se désigner au pupitre.
Il désigne une personne sans constituer un secret ni une preuve de son identité.
_Avoid_ : Mot de passe, code PIN, code de pupitre distinct.

**Désignation opérateur** :
Choix de l'opérateur au nom duquel les prochains gestes seront déclarés au pupitre, à partir de son matricule.
Elle couvre la saisie et la validation du matricule, puis le maintien et la fin de la désignation.
_Avoid_ : Connexion de l'opérateur, authentification de l'opérateur, login.

**Fenêtre opérateur** :
Période temporaire pendant laquelle un opérateur reste désigné pour enchaîner des gestes au pupitre.
Elle se termine par l'inactivité ou par son action « J'ai fini ».
_Avoid_ : Session opérateur, session de connexion.
