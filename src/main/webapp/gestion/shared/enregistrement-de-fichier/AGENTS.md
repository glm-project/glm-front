# Enregistrement de fichier

Noyau technique de `gestion` : remettre au navigateur un fichier produit par le serveur, sous le nom que le
serveur lui a donné (`Content-Disposition`). Partagé par les exports du coût de revient et du rapport
d'activité.

- **FichierExporte** : le nom et le contenu reçus, sans transformation.
- **EnregistrementDeFichierPort** : le port ; `EnregistrementDansLeNavigateur` le réalise par un lien de
  téléchargement temporaire.

Aucun contexte métier n'est importé ici.
